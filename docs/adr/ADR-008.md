# ADR-008: Versões da stack Node: NestJS 11, TypeScript 6.0 e Jest 30

Data: 22/10/2026 · Status: aceito

## Contexto

Em 22/10/2026 as versões mais novas eram NestJS 12.2 e TypeScript 7.0. O NestJS 12 é publicado só como ESM, o que obriga o Jest a rodar em modo ESM experimental, sem `jest.mock` com hoisting. O TypeScript 7 é o compilador nativo, fora da faixa suportada por ts-jest (`<7`) e typescript-eslint (`<6.1`).

## Decisão

NestJS 11.2.7 (CommonJS), TypeScript 6.0.3, Jest 30.5 com ts-jest 29.4, Node 22, pnpm 10.34. Os pacotes Node compilam para CommonJS com `module: nodenext`. Todas as versões ficam exatas (`save-exact`).

## Consequências

Ferramentas de teste estáveis e documentadas para o prazo. A migração para NestJS 12 e TypeScript 7 fica como dívida para depois da entrega, quando ts-jest e typescript-eslint suportarem as novas versões.
